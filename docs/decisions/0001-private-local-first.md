# ADR 0001：私人、局部自动化、数据优先的参考库

状态：本轮实施。日期：2026-09-25。

## 背景

旧项目按角色复制采集/看板脚本，分类继承搜索词，逐图说明与人工选择边界不清。用户要求直接扩大工程规模，后续自行调试拍摄闭环；主目标仍是 cosplay、日常人像、社交和审美探索。

## 决定

用一个 FastAPI/SQLite 领域后端和独立 Web 界面代替按角色生成业务逻辑。保留旧资产作为只读迁移源，图片按哈希存储，业务数据与图像分离。网页不直接爬虫或暴露密钥，长任务由本地执行器运行，另提供可审阅任务包。默认私有，不自动公开素材。

采用可解释的确定性门槛检查流程完整性，不以分类模型置信度代替人工审美；没有证据的字段不默认通过。参考图片、AI 推断与人类确认分别记录，变更通过指纹撤销过期资格。

用独立 ZIP 实现现场离线，而不是先建设难以验证的大型 PWA 缓存和跨设备离线编辑系统。代码意图记录保留在 Git；Notion 是可选视图。

## 代价与后续

单服务 SQLite 不适合跨地域多写入节点；未来有真实多人需求再做账号/对象存储/任务队列，不先制造复杂度。浏览器采集依赖平台当前页面，可能随时受阻；既有任务包和人工导入不依赖该执行器。原片哈希保证收到的字节不变，不保证图片内容正确或拥有公开使用权。
