## 验收标准

- 多个角色复用同一套服务，不复制硬编码脚本；只填角色名可建项目，额外要求完整保存。
- 独立图像原始字节不因预览而改变；选择和反馈持久保存；重复导入不重复或覆盖选择。
- 搜索分类不等于图片事实，未知/错误素材/失效核验不能成为正式现场卡；图片和需求变化撤销旧确认。
- 资料卡有实际可说出口的引导、摄影师动作、安全降级、光线事实与推测分离、PS 路线；AI 草稿和用户确认独立。
- 离线包包含实际独立图像与文字；Notion 导入报告丢图/未解析项；任务状态与实际结果一致。
- 私人数据和图片接口需访问控制，密钥不进 Git；提供迁移、备份、完整性检查、测试和 Codex 接手入口。
