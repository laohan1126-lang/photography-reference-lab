## 实测与用户正例（2026-10-18 追加）

原 .venv 实际缺 httpx，第一次调用在 import 阶段失败，没有执行搜索；失败证据保留于私有 before/kana。使用本机已有且依赖完整的 Python 3.12，不安装依赖、不改日用启动器，执行相同未改动适配器：有马加奈 0 张 / 64.969 秒，王昭君长夜焕生 0 张 / 83.547 秒。小红书报告登录受阻；Pinterest 被代码报告 usable，但随后正常 observe 看到登录弹层，不能把这一状态当成成功访问或无资源。

用户明确反馈：“我去我明说了我很喜欢这张这张好牛逼 如果没被选中这张就是系统有问题的”。截图中的 Pin 标题为“Кана Арима Косплей”。本条是该张图片的人工正例，不推导永久审美规则，不扩展为整批认可。

随后同一 Edge 会话的 Pinterest 已显示登录后的正常搜索页面，登录状态变化原因不作推断。从可见搜索结果定位 Pin 874965033874150534，正常打开发布页，读取实际渲染的 736×889 currentSrc，保存平台图片原字节并逐图查看，与用户截图画面一致。图片、截图、来源、哈希及用户原话保存于私有 `.local/search-quality-20261018/owner-positive/`。页面显示发布账号，但原摄影师/首发来源尚未核实；不把平台发布账号宣称为原作者。没有写正式数据库或冒用 K/I/M/X。

可复现根因：实际标题送入现有 result_metadata_allowed 返回 false / needs_detail_evidence:cosplay,character；即使英文标题 Arima Kana cosplay 也返回 needs_detail_evidence:character。Pinterest 调用方将这个“尚缺证据”直接 continue，当作丢弃，而没有打开发布页、取得大图、交给视觉审查。该结论来自实际函数执行与当前可见 Pin，不宣称原未登录基线曾采集到该 Pin。

首次主要改进范围：Pinterest 的“搜索卡片 → 发布页独立图 → 待视觉审查”边界。保持明确文本反证过滤及 schema2 不伪造 preflight；标题缺失/外语只意味着需要看图。正文/图片只读目标 Pin，不取推荐区替代；读取实际 currentSrc，不改写 CDN；登录弹层导致受阻并停止本来源。只在已界定预算内保留候选。用户明确正例单独计数，不塞入自动检索成功率。

由于登录状态已改变，开始额外的未改动代码 authenticated 基线，使用原任务和预算、独立 evidence 目录。后续对比不能将登录恢复算作代码改进；摄影审美认可仍由用户决定。
