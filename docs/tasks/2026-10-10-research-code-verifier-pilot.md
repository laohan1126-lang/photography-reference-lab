# Real research / code / independent verification pilot

## Original intent and boundaries (before implementation)

The owner requests actual parallel AGY Headless research and Claude Code routed
by the existing CC Switch MiniMax selection, with an independent Codex Verifier.
The course should distinguish observed video actions, photographer speech,
independently sourced explanations and project suggestions/unverified inference.
Existing video links, timestamps, images, old cases and personal learning-state
boundaries must remain usable. No complete new player or general agent framework.

Verified remote baseline: `codex/cc-minimax-delegation-pilot-20261010`,
`c217f81f366a28eee5eb32c271fcf2e6f64ae346`. Integration, CC, AGY and the protected
Verifier each have a separate worktree. Main workspace and original photography
data are excluded. Global permissions, providers, proxy and credentials are excluded.

## Observable acceptance

- Audit effective MiniMax routing before any real CC call; record real responses,
  PIDs, UTC intervals, exits, tool events and settings/protected-standard hashes.
- Freeze the independent Verifier's acceptance and tests before external dispatch.
- Launch AGY and CC with overlapping process lifetimes; label honest partial results.
- AGY must supply actual source material and verifiable video moments, or explicitly
  identify blocked reading / missing audio-video evidence without invented details.
- CC implements a generic small evidence display using clearly simulated fixtures,
  with exact-file edit permissions and no shell, commit, push or private-data access.
- Independently test source, timecode, evidence status, injection, legacy behavior,
  desktop/mobile readability and no automatic private-state writes. At most two
  controller-directed rework rounds; no weakened frozen standards.
- Deliver four factual reports and only owned branch paths. Create a project-only
  orchestration Skill and real isolated discovery tests only if basic orchestration,
  parallel execution, independent acceptance and delivery requirements succeed.

## Blueprint

Python/FastAPI serves an existing plain JavaScript/CSS course reader. Reuse its
case renderer, HTTPS validator, escaped text, source registry, timestamp link and
read-only preview/test fixtures. CC owns only gateway JS/CSS and a dedicated
development test. Root owns research integration, reports and delivery. Verifier
owns its protected external test originals. No state/API/database/backend changes.
