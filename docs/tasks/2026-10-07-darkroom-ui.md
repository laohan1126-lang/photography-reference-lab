# 暗房式界面 · 2026-10-07

## 用户意图

“幫我這個倉庫重新設計一下ui 符合這個攝影參考項目也最好有點高級感 codex設計的太醜了。”

保留现有信息架构、导航文案和筛选流程。只改视觉语言，让拍摄参考与摄影学习看起来是同一个私人摄影库，而不是通用后台。

## 实施前简报

- 现状：参考页是浅纸底 + 深绿侧栏 + Inter + 13px 圆角统计卡；学习页是另一套白底绿色编辑页。图片被面板压住。
- 技术：沿用 FastAPI 静态 HTML/CSS/JS，不引入构建工具或新依赖。
- 风格：摄影图库（深底、照片为主、控件退后）。设计读法：私人摄影参考工作台的视觉重做，画廊优先，原生 CSS。参数 variance 5 / motion 3 / density 6。锁定深色，不在页面中途翻转主题。
- 色彩：冷炭灰画布 + 骨色文字 + 单一赤陶强调色。圆角只用 2px（画面、输入）和 4px（对话框）。主按钮用骨色填充、深色文字，避免再一块绿色。
- 不修改：数据库、原图、人工选择、采集器、路由、导航标签、K/I/M/X 语义。不提交、不推送、不合并。

## 可观察验收

1. 拍摄参考与摄影学习共用同一套深色画布和强调色，桌面与约 390px 宽度都不横向溢出。
2. 照片区域比面板更亮、更完整；统计不再是一排白卡片。
3. 主按钮、输入框、焦点环文字对比足够；淘汰 / 保留等选择仍能区分。
4. `node --check web/app.js` 通过。浏览器里点开参考页和学习页，确认主要视图能渲染。

## 结果

- 参考页、图库和学习页改为同一套深色画布。统计改为分隔数字，照片区用更深的底。主按钮为骨色，当前项用赤陶。
- 本机 `http://127.0.0.1:18765/` 已在提供这套样式。桌面看过挑参考、图库、摄影学习；390px 宽度下参考页 `scrollWidth` 等于视口，底部筛选条为固定定位。
