# 冻结验收标准：视频案例证据分层

冻结用途：独立验收后续课程候选。标准从当前课程资料、现有 HTTP/Chromium 回归和用户边界独立推导；不规定实现者必须使用的字段名、组件名或 DOM 结构。

## 范围与现有接口

现有公共入口是 `/learning?course=sword-perspective-chapter`；课程目录经 `/static/learning-atlas.json` 提供。视频案例可由案例播放出处及起止时间识别。现有案例字段包括 `url`、`playback.start/end`、`title`、`author`、`caption`、`images`、`source_summary`、`review` 和 `rights`。既有 Playwright 回归使用隔离临时数据目录，不打开用户日用数据库。

## 必须通过的行为

1. 对实际视频案例逐例清楚分隔四种信息。可用任意字段或渲染方案；验收看读者实际看到的内容和来源关联，不检查固定 key：
   - A：该画面/帧确实能看到的内容，注明对应视频及时间位置。只能陈述逐帧可见信息，不能把项目推断写成画面事实。
   - B：摄影师本人可核实的说话内容。若没有能核对的原话，应直说“未找到/未核对本人原话”等未知状态；不得把课程解释、字幕转述或 AI 分析伪装成引号原话。若引用，能从案例入口回到对应片段。
   - C：专业解释及其独立依据。明确依据来源能支持什么、不能支持什么；无独立依据时显示待验证/推断，不能用“专业已证实”代替出处。
   - D：项目拍摄的可执行应用，或醒目标为待验证的推断。不得把应用建议写成视频摄影师的指令或影片已证明的结论。
2. 来源和时间码要彼此相符：案例所属视频应与播放链接相同；可见的片段起止与数据及播放起点相符；关联案例的图片、描述、说话者不串到别的视频或邻近片段。越界、反序或无效时间应被拒绝或安全省略，不能造出貌似有效链接。
3. 没有可追溯证据的声明不能被标成已核验/已证实。显示的核验状态要能追到实际依据和具体范围；只核一帧不能扩张为整段视频已核实，只看摘要不能声称逐帧观察。
4. 课程内容按文本显示，不执行字段内 HTML、事件属性或脚本。链接只允许预期的 HTTPS 视频/来源网址及必要的同源静态资源；`javascript:`、凭据嵌入、伪装域名和不安全跳转必须不可点击/不可执行。使用新窗口的外链应有隔离属性。
5. 桌面 1440 px 和手机 390 px 下，案例、四层证据和长链接可读且无页面/阅读器横向溢出；手机布局不依赖 hover。
6. 兼容原有无补充证据字段的课程案例：旧标题、说明、原图/原图失败提示、原来源链接、视频播放链接和时间段仍可读；缺失新字段不导致崩溃、虚假占位或错误“已核验”。
7. 单纯打开课程、切换章节/案例、展开解释/来源和关闭阅读器，不发起私人记录写入；服务器端技能状态、认知自评和学习记录保持不变。草稿交互只有显式保存才允许写入；本验收不把“页面看起来没变”当作后端未变证据。

## 独立语义样本（用于判断，不是待实现文案）

| 类别 | 可接受的正例 | 必须拒绝的反例 |
|---|---|---|
| A 画面观察 | “02:12 帧里，手与道具轮廓重叠；只陈述当前画面。” | “摄影师在 02:12 把机位降低了。”（单帧看不出动作/机位变化） |
| B 本人原话 | 有对应视频时间码、能回看核对的短引文；或“本段没有核实到摄影师逐字原话”。 | 把课程作者写的建议加引号并署给摄影师；把字幕概述冒称本人原话。 |
| C 专业解释 | “透视解释来自有出处的光学教材；适用于投影关系，不证明本片采用了某焦距。” | “专业已证实此片用了 24mm”，但无 EXIF、作者陈述或其他独立证据。 |
| D 应用/推断 | “项目建议：试拍时保持动作，只后退一步；背景关系可能改变，需复拍验证。” | “视频证明后退一定改善所有持剑照片。” |
| 状态 | “本站逐帧核过 02:12–02:30 的这些可见动作；不是全片逐字稿。” | 一处无来源的肯定语被标为“已验证”。 |
| 安全 | `<img src=x onerror=...>` 作为字面文本显示；不产生节点或脚本执行。 | 字段文本生成可执行图片/脚本节点，或危险协议锚点。 |

## 验收边界

自动浏览器回归能证明候选页面、目录链接、响应式几何、状态写入边界及恶意字符串处理；它不能证明远端视频确实说过某句话、专业解释本身正确、课程已完成整段视听核验或主人认为讲解清楚。对真实语音、帧事实及用户学习效果的核验必须单独标为未验证，除非本轮有实际观看/听取或用户验收证据。禁止访问用户私人学习数据库或以合成文本代替真实视频证据。
