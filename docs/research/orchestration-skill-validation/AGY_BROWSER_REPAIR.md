## 问题链与修复边界

首次 AGY 会话遇到模型 API 的 region 拒绝。这是模型入口故障，不是浏览器权限或网页拒绝；用户恢复原有代理后才继续。Headless 命令授权是另一个门槛：默认 Ask 在 headless 下自动拒绝。Chrome 登录/现有连接状态又是独立前置，不能用一项授权代替另一项；本次沿用在线 Chrome，不改账户或浏览器设置。

Windows 上含空格的 quoted-path 前缀规则没有命中。补充五条完整 literal 命令规则后，native AGY 实际执行了桥接 preflight；`agy-bridge-ready` 的本机结果为 PID 19496、UTC 2026-10-11 05:12:16.812559–05:12:54.845920。官方文档解释 Windows 无法可靠拆词时要求完整原始命令匹配；本机为何进入该分支尚无源码级证明，以实际调用为证。

最终共新增 **12** 条有限规则：6 条完整命令（其中一条为后来补看的顶部人像）、2 条来源域名、4 条精确文件/证据目录读取规则。AGY 会重新排版设置 JSON，不能隐瞒字节哈希变化。完整当前 JSON 恰好等于原设置加这 12 条 allow，备份原哈希 `54f8eb9c…15048` 保持；guarded rollback 预演 PASS，有后续无关变动时拒绝覆盖。当前字节哈希 `46b48bff…59a0`。保护和安全比较记录在 `.local/agy-flow/{protection,permissions-change,integrity-final}.json`，完整配置不提交。

本次没有全局安装 Skill、安装依赖、借用用户标签页、重启共享 BrowserSkill daemon 或修改代理凭据。原始截图、工具事件、研究全文和设置备份留在 Git 忽略的 `.local`。
