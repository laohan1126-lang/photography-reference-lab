# 机位、焦段与透视｜这一轮学到的拍法

[打开完整领域试读](http://127.0.0.1:18770/learning#domain=perspective)

先决定人物要自然、显高，还是突出手或道具，再分别调整距离、高度、朝向和取景。

- 比例怪，先查谁离镜头最近。后退再取景，比一直压低相机更容易找到原因。
- 原地变焦改变画框；移动机位改变近远关系。把短焦照片裁到相近取景，能看清区别。
- 脸、半身、全身分别设高度。相机放低后，镜头是否上仰另行检查。
- 弯线查镜头校正，直线汇聚查朝向，鼻大耳小查距离。三种“变形”分开处理。
- 先看场地退路，再选焦段。组照从环境与全身收到动作、表情和细节，每张增加信息。
- 近手可以制造动感，也可以抢走脸的注意。前倾先看拍摄距离，再一起看头、肩、髋。

进入原有技能后，先读图片笔记；“练一遍”进入训练，训练的“依据笔记”回到对应解释。知识点跨技能复用，来源在每篇的“出处与回看”中。
