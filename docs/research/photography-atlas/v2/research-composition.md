# V2 研究记录：构图中的注意力、视觉重量与遮挡

研究目标：检验“视觉重量 / 注意力路径 / 遮挡关系”能否成为比三分法更深入的认知入口。本文是研究证据与教学决策备忘，不是课程稿，也不修改现有 247 项技能。

## 当前基线与结论

以当前仓库 `HEAD=5335eda2e15e5e57eb7cbfdf9e5aed123d9fb686` 为技能数据基线：14 个领域、71 个模块、247 项技能、205 条来源。原始候选已分列 `composition-visual-weight-diagnosis`、`composition-asymmetric-balance`、`composition-intentional-imbalance`、`composition-edge-sweep`、`composition-foreground-control`、`composition-tonal-figure-ground`、`composition-layer-depth` 等。它们提供较好的知识/控制点覆盖，但相邻项容易形成“术语清单”，还没有单一学习入口把观看者先注意哪里、随后沿什么关系继续看、遮挡如何改变主体轮廓与可读性连起来。

**候选入口：先问“我希望观者先看见什么，随后怎样读懂画面？”** 摄影师不只是把人放到格线交点，而是预判主次关系：脸/眼/动作、亮度与色彩差异、细节和纹理、大小与位置、线条/视线的方向、前后层与遮挡边界。这些是互相作用的线索，不是有固定顺序或分值的公式。训练必须同时允许“主体立即清楚”“延迟发现”“刻意让人物融入环境”等不同意图。

这不是说已经证明该概念是教学学意义的 threshold concept，也不等于“眼睛真实一定按某路线移动”。专业来源多为摄影师方法与案例；眼动研究只对特定材料/任务的注视分布提供局部证据。教学适配价值仍需用户实测。

## 实拍案例：实际像素检查与教学可用性

1. **职业摄影师的诊断/调整记录（仅外链，不把任一帧预判为失败）——Diane Berkenfeld 盐沼草茎。** 本轮重新用 Nikon 原页的实际屏幕像素核验 `distraction-1-before.jpg` 与 `distraction-1-after-fixed.jpg`。原始较宽的一帧里，两根细直立草茎分处画面左右；中间是大片浅色水面，上缘有柔化的绿带，底部有近处草茎/草叶。另一帧里，一根较粗、较长的弧形草茎从上方斜穿至右下方，背景是柔化却更绿、更有细碎纹理的植被。故此前“前帧是繁杂草带/横水线/远岸建筑、后帧是暗而平的水面”的描述错误，现予撤回；像素也不支持把后帧概括成整体背景更简洁。Nikon 作者文字确实称初始背景分散注意，并说改角度后干扰减少；照片本身能展示摄影师如何改变主体与背景关系，但观看者可以不同意其结果更清晰。应让学习者先独立观察，再给出作者解释。图像署名版权未授权转载，只外链。误读原因：早前记录把作者文字的诊断结论和旧的观看印象带入了像素描述，没有重新确认最终展示的图片本身；文本/图注不能替代像素复核。

2. **反三分法实拍肖像——Tamara Lackey 中央构图笑脸。** 已打开第一张原图像素：孩子的脸和开放笑容位于画面中间，眼部/口部表情明显；衣服的暖色块在下方形成次级色彩区域，树叶/背景线条与浅景深起辅助作用。它说明把主体移离中心并非先验要求。来源作者把目标描述为孩子的喜悦，并说线条和秋色帮助支撑焦点。这个案例挑战“先找格线”，但它本身并不是注意路径的单因素实验，也没有对照版。版权 © Tamara Lackey，不复制图片。

3. **延迟揭示 / 多主体——Rackham Fstoppers。** 已分别打开文章中成群海鸟、单只海鸟、渔船上黄白浮标等原图像素。能直接看到成群/单体的大小、明暗、色彩饱和度、清晰度与周围空间关系不同；文章的浮标例是密集黄白物、红色标记、网与雾混杂，确实会产生多个颜色/纹理落点。作者讨论了“次要物先吸引、主物后被发现”的可选表达。它是作者案例/判断，不是对所有观者的实测。版权未授权转载。

## 证据层级与教学边界

### 来源直接支持的内容

- 摄影师能把主观意图（观者先读到什么）与画面元素安排联系起来；Nikon 的 Lackey、Berkenfeld 案例具体说了背景清理、分离、颜色/线条、机位变化。
- Rackham 与 Wilkinson 把“视觉重量/平衡”作为诊断语言，并列出可见因素；同时他们没有提供可复现的物理单位。Rackham 原文评论区中的反例也显示，大小与对比/形状/语义可能发生竞争。
- 有限的眼动/裁切实验支持：注视分布、显著性与选择/构图存在可研究的关系；闭合框景在一项小样本研究里更集中注视。人物/语义、目标任务和图地结构会改变判断。
- 心理视觉研究支持遮挡轮廓需要被分配到前景/背景对象；遮挡对快速目标检测与身份识别/记忆的作用可以不同。不能从“被挡了”直接推导“失败”或“必然仍可读”。

### 教学适配（不是职业共识）

- 将“视觉重量”具体化为一次可证伪预测：在未提示时标出自己第一眼、第二眼的目标，说明可见线索；再请另一位观看者独立标记，用差异而非教师权威作为讨论入口。
- 针对同一实拍，标记脸/眼、明暗色块、细节、线条、前景遮挡和轮廓接触，逐张说明主次变化。若重拍，尽量只改变一种构图变量；现实摄影无法完全控制背景投影、表情、动作、光线等，应逐项列为混淆变量。
- “视觉重量”适合作为谈论竞争/平衡的临时模型，不作为相加评分、固定阶序或对所有人统一的注视预测。真正的观看路径需要眼动实验；简短的人工首眼报告不是测量等价物。
- 迁移测验开头须给未分析的许可照片和中性标题，隐藏原文件名、图说及任何人物/遮挡线索；首问仅让学习者记录自然第一注意点、其后的注意转移或“没有转移”，不要求当场给原因。答完后才展开提示，邀请其用画面线索解释注意分配，并提出一个符合意图的调整及可能副作用。若图像有可确证的遮挡边界，再把边缘归属作为可选问题；不能强迫学习者将不相关的图解释成遮挡例。此序列是项目教学设计，尚未通过学习者实测验证。

## 为什么可能比简单三分法深入

三分法回答的是“主体相对画框的一个位置变量”，可以快速建议偏置位置，但它本身不能解释：为什么居中笑脸仍可能最有力；为何画面某侧的小高反差元素比大主体更抢眼；视线/线条把观看带向哪；前景物的边界是否让脸或道具与背景黏连；刻意迟显主角是否正是表达目标。新入口把**位置从规则终点变成一个候选因素**，让学习者围绕主次、过程、图地边界和目标意图观察一张新照片。

这也不是“重量模型取代三分法”。Frontiers 论文指出，三分法/黄金比例不一定获得实验偏好支持；裁切研究里参与者选择的显著性/注视中心趋向画面中心只描述该类裁切行为，不能反向变成中心构图处方。摄影师应该能在中心、偏置、平衡和刻意失衡之间按表达目的切换。

## 关键未验证问题 / 进入样板前需要决策

1. **是否把视觉重量与注意路径合并为一个认知入口？** 专业文章把它们相连，眼动研究也可测部分关系；但“预测首眼”“判断平衡”“读出语义”是不同任务。较安全的入口把它们串成观察问题而不合成一个综合评分；各技能仍负责不同控制变量。
2. **遮挡关系是否为此入口的组成部分，还是独立入口？** 视觉上的遮挡既制造前后关系，也影响轮廓、识别与注视；但现有摄影专业案例对边界归属/遮挡的直接教学少，心理学研究也多是简单刺激、非摄影任务或动物神经记录。可把“遮挡边界是否让主体可读”作为子问题，暂不称其为同一因果模型。
3. **“注意路径”措辞是否过强？** 专业作者的线条/方向建议只是意图指导。除非具备眼动测量，教学内容应称“预期注意顺序/可能的视线路径”，不能说观看者的真实 gaze path 已被验证。
4. **学习者可测试性：** 尚未招募/观察真实学习者，也没有对新照片迁移的通过率数据。当前只是有出处的样板决策证据，不代表用户会获得新能力。
5. **图片展示：** Lackey、Berkenfeld、Rackham 专业原图未见通用转载授权，样板应提供作者/原文外链，另用 CC BY-SA 4.0 迁移图满足展示许可；勿把“网页可以打开”当成可复制授权。

## 对后续样板的决策建议（不是课程内容）

保留为**优先进入 V2 原型候选**，因为来源能串起：摄影师谈主次/竞争 → 职业者的取景调整 → 反例（居中、刻意延迟）→ 科学文献提供局部观看证据并限制过度声称 → 许可图可做新题材迁移。原型应先让学习者对夜间建筑照片作无提示首眼/后续注意记录；再提示查看不同亮度、面积、颜色与人物尺度，并把遮挡边界列为可选项而非预设答案。Nikon before/after 应先隐去作者解释，让学习者观察两帧区别，之后再揭示摄影师说法；学习者可指出作者“更少干扰”的判断与其自身像素观察不一致。

不建议把候选变成“九种视觉重量要素排序”“五步注意轨迹”或给照片打主次分数。这些没有直接来源证据。关键验收是学习者能否给新照片提出可检验的视觉问题，并用画面线索支持判断；人类注视是否真的一致仍需独立测量，摄影是否更好则取决于意图。
