# 摄影专业内容独立复核：V2 三个认知入口

日期：2026-10-09  
审查对象：`.local/atlas-v2/docs/research/photography-atlas/GATEWAYS.json`（composition、perspective、light）及其研究备忘。此报告仅作审查，不修改产品文件。

## 结论

核心摄影原理总体可靠，抽核内容未发现会教错摄影几何或曝光的高置信度事实错误。课程能分开可见线索、作者解释、项目推断和拍摄条件未知；没有将“低机位必然有气势”、固定45°灯位、焦距数字造成透视压缩写成规则。摄影来源多为摄影师方法与真实案例，眼动研究也有限定样本和任务，来源标注总体符合其支持范围。

**建议发布前修一项教学范围问题：构图入口把“注意力竞争”与“遮挡边界”并列为核心，但实拍练习主要训练前者。**若本轮不增加真正观察遮挡的案例/练习，应把标题和学习结果收窄为注意力竞争，将遮挡保留为附带检查项；若保留双核心，至少要求一个练习定位具体遮挡边界、前后关系及轮廓是否粘连。其他问题均为可选增强。

## 实际像素抽核

- **构图迁移图**：直接打开提案所用 Commons 960×1280 图像。可见夜间佛塔/寺院：暖金尖塔在上方中央，浅色大圆顶占画面中部，左侧白色多层建筑，右上强亮灯与耀斑，下方中央偏左有穿浅色衣物的人物。课程对主要亮度、色块、面积与位置的描述吻合；原文件名确有“忽略前景人物”的方向提示，课程隐藏了原名，并说明这只是注意观察材料，不是遮挡控制案例或专业质量背书。未发现现稿重现已撤回的“大型左前景人物”错配。
- **机位迁移图**：直接打开提案中精确 URL 的 960×1200 角色照。人物戴护目镜、黑背景；一只戴手套的手向前握住大型机械道具，另一只手下垂；烟雾在道具上方，蓝色发光管向画面右下延伸，下方有局部木地板，脚未完整入画。现稿的手、道具、烟雾、光管及缺少完整地面参照的描述基本准确。课程没有从 18mm EXIF 推出机位/距离，也没有从单张图量化手或道具的放大倍数，边界恰当。
- **光线迁移图**：直接打开提案中精确 URL 的 960×1280 窗边人像。窗在画面左侧，人物坐右侧，身体与脸朝向不同；脸部明暗不均，窗洞、周围暗墙与人物受光并不等量。课程把“窗光从画面左侧附近进入”作为工作假设，同时保留反射光、其他环境光和后期等未知，符合单张成片的推断边界。
- **机位职业案例**：直接查看 Ed Gregory 报道配图 1600×867 的 16 格视点网格。画格中是同一女性和灰背景，头部/脸部朝向、可见头顶与下颌范围有所变化；表情和姿态也变化，网格没有逐格精确角度标签。现稿据此练习描述投影差异，并指出不能分离高度、俯仰、表情等因果，准确。
- **闪光职业案例**：直接查看 Strobist 原文链接的 Shade、Dark、Final 三张 800px 图。Shade 是阴影环境下人物与墙体较亮的基准；Dark 收光圈后人物和环境一起变暗但墙柱仍可辨；Final 人物与墙体被闪光重新提亮，姿势也变化。课程将其作为流程示范而非单变量实验，并指出灯数、姿态、取景等混淆项，符合图像与原文。

**未能独立确认：**Nikon 盐沼两帧和 Jane Allan 头部转动对照在本轮浏览器中能读原文/图注，但网页图片区域未稳定呈现可检查的大图像素。我不把自己的复核计作这两组图的像素确认。现稿对盐沼逐帧描述与研究备忘相符，但该像素证据依赖实现者复看；Allan 图像分析依赖原研究记录。可保留案例，同时把审查结论限定为我未独立复核这两组像素。

## 必须修复

1. **构图入口中“遮挡边界”学习目标缺少同等练习证据。**盐沼对照训练主体/背景竞争；中心儿童肖像训练中心与偏置没有固定答案；夜景迁移图也明确不适合做遮挡控制案例。正文解释遮挡可能分层或粘连，但练习没有要求学习者在照片上定位某条遮挡边缘或预测改变遮挡的后果。建议二选一：
   - 收窄题名、学习结果和导航说明，以「视觉注意/主次竞争」为主体，将遮挡作为相邻技能/可选检查；或
   - 保留双核心并增加至少一个具有可见前后遮挡的照片练习，要求标出被遮挡轮廓、判断前后关系、指出仍可能粘连的边缘，再揭示项目自己的像素观察及推断边界。

收窄是较小改动。原因是当前标题与学习承诺让读者期待两种能力都获得实际训练。

## 可选增强

- 盐沼专业对照的作者文字说背景竞争减弱；现稿正确提醒这不是观看者测量。原页链接旁继续显式保留“作者的判断”，避免 UI 用成功/失败徽标替作者下结论。当前 JSON 没有此类错误标签。
- 透视练习的 0.6/1.2m 等大标记以及后退1.8m，是教学自建的理想直线投影算例，比例趋势正确。可再写出“同尺寸、近轴、未计畸变/裁切”的简短前提；正文已有“理想直线投影、靠近画面中心”，以及真人手脸不等大、不能从照片算身体尺寸，所以这是清晰度增强。
- Strobist 把闪光概括为“光圈控制”，属于其入门工作语境的简化。课程明确光圈和 ISO 均影响环境与闪光，并限定常规同步、闪光脉冲，讨论 TTL/HSS/慢门，现稿可以保留；未来摘引原文时不要删去本课边界。
- ToMar 窗边图文件页 Summary 与许可段有 3.0/4.0 标签并存，人物可辨认。课程如实记录两个版本、署名/ShareAlike及上传者关于同意的声明，也没有声称已独立审核模特授权。公开部署前建议再次核对文件页与权利范围；本地原型披露充分，不是本轮必须撤图的理由。

## 来源与事实边界检查

- Rackham 的视觉重量因素被表述为摄影师工作模型，不是普遍权重顺序；大小不被教成永远优先。合理。
- Abeln 的裁切/显著性研究和 Tseng 的小样本闭合框景眼动研究均限定于各自任务、图片与参与者范围，没有推出居中处方或所有遮挡都能引导注意。合理。
- Qiu 的非人灵长类视觉皮层摘要、Meng 的摘要级遮挡研究被标成有限机制线索，不是摄影学习证据。合理；可删减以降低密度，但当前边界说明谨慎。
- Banks 等人的透视/观看距离论文与 PPA 摄影教材分工明确：论文支撑视点、观看与投影讨论；职业文章只作方法案例。没有把心理读感冒充几何定律。
- 机位—俯仰—滚转区分正确；仅凭照片线条不能唯一反推机位，透视校正/裁切可能改变线索。相机固定只变焦改变取景、不自行改变透视；为保持占比而后退会改变透视，现稿准确。
- 光线部分区分方向与硬软、脸朝向与光源、环境与闪光贡献；常规同步下的快门近似附条件，并讨论环境拖影、HSS、TTL、光圈/ISO对两层的影响。未发现把“快门只管环境”写成无条件规则。

## 复核后结论

按上方必须项收窄构图入口，或补上真实遮挡练习后，三门课的摄影事实、案例边界与来源标注可以进入下一轮交互/教学验收。用户能否迁移仍需用户本人测试；此审查及 Agent 练习不能替代学习者能力证据。


## 第二轮复核与关闭状态（2026-10-09）

复核对象为更新后的 `GATEWAYS.json`。本轮直接打开 Allan 原图 URL `https://thelenslounge.com/wp-content/uploads/2020/03/butterfly-light-portraits.jpg`，以浏览器显示的完整 800×565 并列图检查像素；没有依据图注替代图像观察。

### 已关闭

- 构图入口现名为「先看见什么：画面里的注意力竞争」，结果明确说遮挡只是相邻可选检查、不认证遮挡分析能力；技能列表已移除 foreground-control 与 layer-depth。核心题名和能力承诺收窄，解决第一轮最重要的范围缺口。
- 新夜景迁移题要求学习者先独立记录注意落点，再自选目标、援引两条可见线索、预测调整影响及代价/替代解释。展开分析明确允许不同目标，不把作者文件名当答案；也提醒这张图不是遮挡控制案例。它是有证据链的迁移任务，较之前只回答“先看见什么”更完整。
- 原图像素确实支持夜景揭示中的主要对象、亮度和位置描述；移除摘要级机制研究出现在课程正文/引用的做法也降低了证据超范围风险。构图的注意力主线目前没有新的高影响事实错误。

### 仍需修复

1. **遮挡仍在正文中被当作核心练习步骤，和“相邻可选检查”不一致。**虽然结果与技能列表已收窄，但课程问题段仍以遮挡解释为何前景切碎轮廓为开场；观察对照仍单列“前景挡住主体”的专家行；原理段把边界检查作为两步方法中的第二步；中心/偏置对照练习还要求检查边缘或遮挡。建议将这些改成清晰标示的“可选延伸”，不纳入本课核心练习和掌握反馈，或从核心教学链移出。否则使用者仍会收到一项与声明相反的教学承诺。这是本轮剩余的必修项。
2. **Allan 对照图的观察题要求分析眼窝，但图中人物戴深色太阳镜。**像素复核确认两幅中眼睛都被遮住；不能从此图检查眼窝受光或眼神光。请将该题可选线索限定为可见的鼻影、脸颊亮暗或头部朝向，并在揭示中明确“本图不能评价眼窝/眼神光”。原文关于眼窝的一般教学文字可以作为文字来源保留，但不能说这张对照图的像素证明了眼窝变化。

图中头部朝向/表情有变化，鼻部及脸侧阴影差异较细微。我能确认存在可讨论的细小明暗差，但它并非一眼显著的严格对照；建议把“鼻影略有变化”保留为弱观察，避免强断言它仅由转头造成。现有文案已承认姿势、表情、曝光变化和非受控条件，因果边界合适；仍应避免把可见差异写得比像素明显。

### 当前结论

构图主线和迁移活动的第一轮缺口已关闭，但“遮挡只作可选检查”尚未在正文练习中贯彻，且 Allan 图片的眼部证据与练习提示错配。因此三门课不应标成无保留通过；完成上述两项文本收窄后，可进入 UI/学习者验收。本报告没有修改产品文件，也未更改 Git 状态。
