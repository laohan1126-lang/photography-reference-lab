# 光线方向、面部塑形与环境光/补光：V2 研究备忘

## 本轮研究目标

基于仓库 `5335eda2e15e5e57eb7cbfdf9e5aed123d9fb686` 的正式技能树，研究一个能把已有基础技能连成专业判断流程的候选认知入口。重点不是再定义蝴蝶光、侧光或补光，而是让学习者看出：

> 人脸上的明暗结构由光源方向与面部朝向共同形成；补光会叠加到环境曝光上，提亮暗部不等于自动保留原主光塑形。判断“补多少、从哪边补”，要同时读脸部阴影和环境中的光向线索。

该候选与现有技能 `light-001`（判断人脸主光方向）、`light-010`（窗光）、`light-017`（选择曝光参照）、`light-021`（先定环境光再加闪光）、`light-025`（闪光塑脸）、`light-026`（补光与现场主光关系）相连。它应作为跨技能入口，而不是新增同义技能。

### 案例像素观察记录

- Allan 对照图：左右为同一人物、近似相同背景与日照条件；左图鼻影较紧凑，右图鼻影向脸颊侧移，说明面部朝向的小变化会移动阴影图案。也可见头部角度、表情及身体姿势略变，因此不能把两张图当成控制实验或单独归因到某个精确角度。
- Hobby 的 Shade/Dark/Final：环境基准图整体较亮；Dark 暗了环境但柱面、墙体仍有可辨结构；Final 人物及墙面获得闪光，人物的高光/阴影关系变得更有方向性。三个取景/姿势不完全相同，视觉比较支持的是工作顺序和“环境层+闪光层”的定性关系，不支持精确光比结论。
- Commons 迁移图：窗的亮面在人物左侧，脸上可见侧前方入射的亮部和远侧暗部；人物身体转向、脸部回看相机，和脸部并非同一朝向。图像提示学习者分别画出窗—脸朝向—相机三者关系，再预测把脸转向窗/背窗时哪些鼻影、眼窝和脸颊区域会变化。实际的补光/反光板数量及强度不能仅凭这张最终图还原；相机 EXIF 的“flash did not fire”只说明该曝光未触发机顶/热靴闪光记录，不证明场景没有其他反射光或后期调整。

## 新手与专业观察的差异

| 新手容易停在 | 专业观察可以进一步追问 |
|---|---|
| “脸亮不亮”“是不是逆光”“用了柔光吗” | 哪一侧鼻梁、眼窝、颧骨和下颌先出现明暗边界？边界方向指向什么入射方向？ |
| 记住“灯在 45° 是 Rembrandt/loop” | 45°是灯相对谁、从哪个观察平面量？人物转头后，三角形/鼻影是否仍在预期位置？ |
| 把反光板或闪光理解为“把脸照亮” | 它是只提升阴影区、整体压平明暗比，还是因角度/强度形成第二组高光和阴影？它和窗/太阳给出的背景光向线索是否一致？ |
| 只看人物主体曝光 | 环境原来的可见层次是什么？压低环境后是否仍有想保留的细节？闪光会落到人物、背景，还是两者都落到？ |
| 用软硬判断光是否好看 | 阴影的方向/落点与阴影边缘软硬是不同变量；硬光也可以服务于图案、质感或戏剧表达。 |

## 建议的教学目标与可观察能力

学习者不只会说出 pattern 名称，而应能够：

1. 从人脸的鼻影、眼窝、脸颊明暗和下颌阴影提出主光大致方向，并说明结论的不确定性。
2. 把光向判断写成“光源—脸部朝向—相机”的空间关系，不把相机轴线误当成所有人脸的参考轴。
3. 区分方向和质量：方向主要改变高光/阴影落点；相对光源尺寸、扩散和反射条件改变阴影边缘过渡。改变其中一个不等于自动改变另一个。
4. 在加闪光前描述环境曝光基准；加灯后判断是提高暗部、建立另一个方向，还是同时改变人物与背景，而不是只用“更亮/更暗”概括。
5. 在新的照片上提出可检验的预测：人物头转向哪边时鼻影会如何移动；把补光移到相机轴线上或降到较弱时，面部立体感和背景线索会怎样变化。
6. 能指出图像不足以确定的信息（灯数、反光板、精确输出、现场照度、后期处理），避免把推断说成事实。

## 建议用来训练观察的变量

变量应由内容作者选取并做标注；不必全部一次讲完。

- 几何关系：主光入射方位/高度；脸朝向；脸的近侧与远侧；相机相对脸的位置；鼻梁、眉骨、颧骨的形状。
- 可见线索：鼻影方向与长度、阴影是否连接到脸侧、眼窝是否陷暗、眼神光位置、脸颊转折、下颌/颈部投影。
- 光质：光源相对人脸的表观尺寸、直射/扩散、阴影边缘过渡；避免把总亮度作为软硬替代指标。
- 亮度关系：环境基准曝光、人物高光与阴影的相对亮度、背景可见细节、补光加入后的变化；不预设唯一正确的肤色曝光或固定光比。
- 环境匹配：背景/周围物体的自然阴影方向、窗/天空/现场灯的主导方向、补光方向是否重合或冲突，补光是否泄漏到背景。
- 动态变量：头部转动、站位/与窗距离、光源距离、补光相对输出。实际练习应一次只改一个变量并记录未控制项，才适合比较。

## 反例与适用边界

- **脸型/骨骼破坏固定角度口诀：**深眼窝或突出的眉骨在较高正面光下可能使眼睛更暗；鼻梁形状会让同一灯位的鼻影连接、长度和位置不同。45°只能当试位起点，不能当通用答案。
- **图案名不是目标：**蝴蝶、loop、Rembrandt 是描述阴影外观的标签，不保证更好看；圆脸强调圆润、婴儿人像、角色妆造或叙事情绪可以有意保留/加强某种效果。Jane Allan 对“适合脸型”的建议应视作该作者的审美经验。
- **逆光不必补正：**人物作为剪影、保留高光轮廓或营造背光情绪时，主动不补脸是有效意图。补亮脸会改变视觉注意力，也可能削弱轮廓光。
- **加补光不等于只填阴影：**同轴弱闪可能降低脸部反差；侧向强闪会创建自己的高光、阴影和投影，可能与窗光/背景不一致。相机预览上看似“亮度正确”仍可能出现双重方向线索。
- **光质与方向相互独立但在画面中共同出现：**柔光可以仍然是明显的侧向塑形光；小而硬的光也可以从相机轴线正面打平五官。不能把“柔”直接等于“平”或“自然”。
- **单张成片不可完整反演布光：**曝光、反射面、环境填充、局部遮挡、后期都可改变可见差异；从最终图推测“只有一盏灯”通常不可证。
- **闪光曝光的规则有设备边界：**Hobby 的例子限定在文中同步速度范围内；HSS、TTL、自动 ISO、频闪、闪灯回电/功率限制会改变控制关系。后续教学应配套设备说明或独立的同步专题，不应从本入口做机型菜单承诺。

## 研究结果的证据分层

**来源直接支持：**同一自然光方向下转动脸部会改变脸上的模式；五官结构影响图案；扩散/表观尺寸改变阴影边缘；反光板/较弱填光能改变阴影深度；Strobist 的单一实拍流程展示先设环境、压暗后再用闪光照人物/背景；Commons 原图实际显示窗光在人脸上的可见明暗分布。

**项目适配推断：**把这些知识组织成“先读脸，再读环境，再决定补光方向与亮度”的跨技能诊断顺序；用鼻影/眼窝/背景影子作观察锚点；加入新图迁移题。这一顺序是为了本地图用户在现场更容易作判断，不是三位来源共同声明的教学方法。

**待验证的教学假设：**先让学习者画出光向关系再揭示说明，会比先看 pattern 名称更能迁移到不同脸型/窗口场景；分别练“头转动”和“只加填光”能帮助区分方向与亮度；该入口可降低无灯时把所有暗部归因于曝光不足的倾向。需要在原型中用未讲过的新照片和真实用户试用验证，不能由 Agent 自评为已学会。

## 建议的观察/迁移检查（研究草案，不是课程成稿）

可先用 Jane Allan 的头转对照作为“识别现象”的共同阅读案例，随后把 Tobias Maier 的 CC BY-SA 图片作为未讲解迁移图：让学习者标出画面中可见的窗、人物躯干朝向、脸的朝向、鼻影/眼窝/脸颊亮暗和不确定项；再问若脸更朝向窗，哪些阴影线索最可能变化、背景会不会同幅度变化、单张图无法确认什么。答案揭示后，要求用不同的陌生窗边肖像再做一次同样推断。

闪光部分以 Hobby 序列检查另一种迁移：先分别说明 Shade、Dark、Final 中环境与人物发生的可见变化；再给一个环境有明确侧光线索的新场景，要求预测“弱同轴填光”“侧前方闪光”“不加闪光”三种选择分别会改变哪些局部阴影与背景。把准确曝光和方向匹配分开评分；审美选择可以不同，评分看观察证据、预测是否可由照片检验，以及不确定项是否说清。
