# 旧版摄影学习页浏览器诊断（baseline 5335eda）

## 执行与结果

- 从隔离工作树 `.local/atlas-v2`（HEAD `5335eda`，检查时工作树干净）启动该提交的 FastAPI/Uvicorn；浏览器为实际 Chromium，页面数据目录为本目录下 `isolated-data/`，`auto_classify=false`。没有连接或写入日用资料库。
- 真实点击路径：首页 →「机位、焦段与透视」→「高度与镜头轴线」→「比较高位、眼平与低位视点」→ 技能页「配套教程」→ PPA 外链。1440×1000 桌面和 390×844 移动端均完成前三层与技能页，保存页面截图及教程区截图。
- 两种视口无水平溢出；无页面异常、控制台错误或请求失败。隔离学习状态 revision=0，技能记录/日志/照片引用均为 0。
- PPA 外链成功打开新标签并到达 PPA URL，但浏览器实际显示 Cloudflare 的 “Sorry, you have been blocked / You are unable to access ppa.com”。没有据此推断或总结 PPA 正文。
- 对正式服务 `127.0.0.1:18765/api/learning-state` 的只读聚合检查在沙箱内被拒绝；提升到授权的本机访问后得到 connection refused。日用学习记录数量未验证，也未读取日用笔记。

## 六项页面学习迁移阻点与一项环境限制

1. **环境限制（不计作日用旧版产品缺陷）：首页领域卡片显示 `FIELD IMAGE`。** 隔离工作树没有复制私有 `.local/learning-preview` 素材，而预览路由从 `web_dir.parent/.local/learning-preview` 读取这些素材；因此本次 14 个卡片都走了缺少 `domainCover` 的回退分支（`web/learning.js:93-97`），显示渐变占位（`web/learning.css:82`）。截图只能证明隔离环境缺图，不能据此断定日用旧版缺少封面或把它列为产品问题。证据：`desktop-1440-01-home.png`、`mobile-390-01-home.png`。**不计入以下六项页面问题。**

2. **领域页到模块页缺少模块层的用途解释。** 透视领域页虽写了领域描述，但六行模块只呈现序号、模块名、技能数量和箭头，没有模块目标/适用问题/推荐先后，用户得逐个点开才能判断选择。模板在 `web/learning.js:158`；证据：`desktop-1440-02-perspective-domain.png`。

3. **模块技能目录没有显示学习顺序或先修关系。** 七项技能是平铺列表；列表展示名称、能力摘要和个人状态，先修技能要进入技能页才显示在末尾（`web/learning.js:173-184, 295, 312`）。这让“先区分高度和俯仰，再练三视点对比”的研究关系没有变成目录里的可执行路径。证据：`desktop-1440-03-perspective-1-module.png`。

4. **技能页首次阅读优先展示研究标签和个人自评，教程被推到首屏下方；窄屏更明显。** 教程区在 DOM 顺序上位于技能头部与跳转条之后（`web/learning.js:298-304`）。实测教程顶部为桌面 y=447、移动 y=759；390×844 截图首屏只露出教程标题开头，未看到教程链接/练习。页面确实提供「配套教程」跳转按钮，可缩短路径，但初次打开仍不是一屏可开始学习。证据：`desktop-1440-04-angle-skill-top.png`、`mobile-390-04-angle-skill-top.png` 和 `diagnosis.json` 的元素坐标。

5. **计划中的专业原文在本次真实浏览器无法访问，页面内没有正文替代。** 技能页只给 PPA 标题、摘要、阅读定位和项目练习，链接以新标签打开（`web/learning.js:205-211`）。本次打开确实落到 PPA，但页面被 Cloudflare 拦截；因此不能从该来源继续阅读或核对。应用展示的摘要/项目任务仍可读，但不足以替代标注的全文阅读。证据：`external-ppa-result.png`、`diagnosis.json`。

6. **该技能没有专业图例/照片案例，难以把文字映射到真实画面。** 页面明确显示「当前没有关联的专业图例链接」；数据中该技能 `visual_examples: []`，空值分支见 `web/learning.js:222-224`，数据位置 `web/learning-atlas.json:2742-2780`。证据：两张 `*-04-angle-skill-full.png` 的下方「关联图例与案例链接」段落。

7. **练习有任务和自定验收句，但无示范结果或反馈环节。** 目标技能的练习要求拍三组并“记录比例、背景和主观感受”，项目验收只有两条自我判断；数据将此标为 `project_designed`。UI仅渲染一段任务和静态列表（`web/learning.js:307-308`），个人状态由用户选择（`web/learning.js:300`）。没有并列示范图、逐项观察表或提交后核对反馈，所以用户可以做完记录，却不能在页面确认自己如何判读了差异。证据：`desktop-1440-05-tutorials.png`、`mobile-390-05-tutorials.png`，以及完整技能页截图。

这六项观察说明：研究资料在页面上能被查到，技能摘要、限制、来源定位、建议练习、自我记录都存在；断点在把来源内容转成稳定可访问的教学、用可见案例示范，以及让拍摄后的判断获得反馈。首页占位图另属本次隔离素材缺失，不能外推为日用缺陷。它们是本轮旧版页面诊断，不是对摄影方法本身的反驳。
