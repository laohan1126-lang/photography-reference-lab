## 目标画像适配

一般人像、构图、灯光和电影运动来源的广度较好；对“漫展中的 Cosplay 现场摄影”这一具体目标，来源明显薄于通用摄影内容。英文和日文专业来源占主导；构图、姿势、现场、灯光和 Cosplay 专题的中文第一手职业教学均被来源图记录为不足。尤其应优先补齐漫展限制下的现场方法、服装/道具差异、后期交付与检查复盘回路。

严重核心空白集中在 E/F/G/H：目标场景内的服装与道具呈现、拥挤场馆方法、现场诊断，以及筛片到后期交付。C、D、B、I 的剩余问题更适合作为重要专项补查，不能因此降低证据门槛。

## 建议搜索顺序

1. **中国漫展现场方法与官方限制**：具名活动/漫展摄影师的实拍流程、短交互、背景变化、距离受限、沟通与让位；逐个活动核验官方规则。
2. **服装与道具分类研究**：分别找小刀/匕首、长剑、枪械、假发、宽袖/裙摆与大型道具的第一手摄影材料，避免不同对象互相代证。
3. **后期完整案例**：职业人像摄影师从 RAW、筛片到交付组照的可访问流程；修图师对发丝/服装边缘、阴影/光色匹配的演示；Cosplay 后期边界需有真实案例。
4. **现场检查与复盘**：摄影师公开花絮/讲评，能看见检查、纠错、重拍与后续验证的实际决策。
5. **复杂光线与短动态**：专业作者对混合 LED/电子快门/闪光冻结的实拍说明，以及单人短视频的动作路径、机位和对焦训练。

具体查询词、各维度证据 ID 和来源限制见同目录的 `coverage_source_scan.json`。上述搜索方向是待执行查询，不是对缺失技能事实的补写。
