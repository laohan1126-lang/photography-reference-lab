# 摄影能力地图研究资料

面向真人 Cosplay / 人像现场拍摄。当前结构：14 个领域、71 个模块、247 项可训练技能。节点数量不是完整性或水平评分。

## 独立材料

- `USER_BRIEF.txt`：用户原始要求。
- `SOURCE_MAP.json`：来源身份、访问深度、资格、作者独立性与 URL 去重别名。
- `SKILL_TREE.json`：完整领域、模块、技能，以及练习、验收、前置与证据。
- `EVIDENCE_MATRIX.json`：技能到实际来源的映射。
- `CLUSTER_DECISIONS.json` / `EXTRACTION_DISPOSITIONS.json`：合并、排除与纠正理由。
- `CONFLICTS.json`：保留摄影师方法与场景条件差异，不平均成定律。
- `TUTORIALS.json` / `tutorials/`：整合后的配套材料及各研究范围的原始推荐，含起读位置、练习、核对深度和适用边界。
- `GAP_AUDIT.json` / `audits/`：独立两轮覆盖、来源质量、原子性审计及真实任务反向查漏。
- `UI_DECISION.md`：三种信息架构比较。
- `raw/`：原始独立搜索、读取、抽取记录；未校正原始置信度不作为最终判断。

## 可信度与个人学习

high 要求至少两个独立作者/机构来源直接支持；相同作者不同平台不是独立来源。medium 包含单一方法与明确标注的项目适配。职业共识指本研究所收来源的一致部分，不证明普遍正确。全文、目录、付费大纲、未观看视频与受阻页面分开记录；后三类不能单独支持正式技能。

练习与验收多数为项目设计，并非摄影师给出的职业认证。涉及自然、角色表达或观者注意力的验收，应事先写明意图、展示条件和反馈者。所有个人状态初始未评估；本人才能记录未开始、学习中、训练中、现场验证或已掌握。专业出处不能证明本人水平。

封面只用于浏览。专业案例是原教程的文字/图注链接，未逐张审阅像素；不得据此声称完成图像审美验收。

## 配套材料与复核

2026-10-08 收录 46 份公开材料：30 篇图文、5 个课程章节、8 个实拍解析、1 篇研究论文、2 个视频。44 份核对过正文，1 个视频核对文字稿，1 个视频只核对官方简介和章节、未观看。每项保留访问条件、作者身份、推荐理由、阅读起点与局限；“看完试一遍”明确为项目设计的练习。

精选材料直接覆盖 14 个领域中的 128 项技能；另外 119 项仍标为未精选专门教程，页面从已读研究原文提供起读位置。这不代表完整课程覆盖，也不以推荐代替正式证据或个人能力评估。

独立追加复核抽查 8 项风险较高的技能、重开 17 个来源，修正 PPA 机位对比的定位段落和日本刀姿势材料的作者家族标识，完整记录见 `audits/review_followup.*`。32 个分歧按具体技能范围逐项关联，不再用共享书籍 URL 推断相关性；保留动态影像分歧位置的多来源归属。
