# Skill evaluation contract

Repeated intent: coordinate authorized research/code/independent acceptance using the proven external-agent handoff workflow, without domain-specific logic or a platform.

Prerequisites: inspected repo and existing experiments, installed authorized AGY/CC, isolated worktrees, fresh verifier context. Discovery trials use fresh Codex processes and native project skill discovery; no prompt listing of the target skill for implicit or negative trials. Restrict trials to planning/read-only so the three cases cannot modify the product or call agents repeatedly.

Outputs: compact project Skill; raw private process logs and sanitized evaluation summary; three requested reports; real tutorial sample with A/B/C/D if evidence is sufficient; frozen independent criteria and actual regression evidence.

Invariants: no credential/permission changes, global install, fake agents, lowered checks, manufactured failure, paid API switch, state auto-promotion, unrelated dirty-work commit or domain content inside the deployed orchestration skill.

Evidence: target SKILL.md read command/tool event (not just self-report); negative absence of target read or external calls; PID/cwd/UTC/exit for actual agents; independent frozen criteria hash; actual artifacts and failures/repairs; source limits and unavailable claims explicit. Three trials are one observation each, not statistical stability. No single-agent baseline means comparative reliability is UNVERIFIED.
