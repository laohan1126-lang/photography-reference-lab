# Fixed display lettering

The two SVG files contain outlines for the displayed words only, not font files or a reusable font alphabet. HTML retains readable text alternatives. User-supplied character art is installed separately under the ignored `web/private/kana/` directory.


The fixed `kana-display-logo.svg` is a Kana display logotype traced from the open-licensed Lobster Two Italic outline (SIL Open Font License); it embeds paths for these four letters only, **not a distributable font file**. Other public theme art is avoided; user-supplied character images remain under ignored `web/private/kana/`.
