The current title in kana-display-logo.svg and Japanese note in kana-wordmark.svg are individually extracted and smoothed outlines of lettering in the user's accepted generated mockup (1672x941; SHA256 5b53aef8021f687910ad22ab9e01c94720f853fe53ee90e197a53bb4a814425c). They contain fixed paths only: no font binary, no main character, no reference photo, and no fake interactive controls. The generated image did not supply a complete font. Small strokes remain limited by the input pixels; this is not a claim of original font recovery.

kana-frame.svg is a code-native decorative film/ribbon layer, an approximation rather than the full painted stage assets in the concept. Original character illustrations remain in ignored authenticated web/private/kana/. The real photo and all controls are separate application elements.
