# External handoffs

Use existing installed interfaces; probe `--help` before using remembered flags. Do not read or copy credentials into prompts or logs.

- AGY print mode: provide a bounded research prompt, isolated cwd, `--output-format stream-json` and a finite print timeout. Use plan mode for read-only exploration where possible. Check the actual model result before testing browser permissions: HTTP/API preconditions can fail before any tool. Do not retry a non-retryable error without an external-state change. Require actual `read_url_content`, browser/MCP, or image-view events for observation claims. Inspect denied actions and generated material separately from the final SUCCESS record. This installed CLI emits `event` plus nested `init`/`step_update`/`result`; do not assume CC's `type` event shape.
- CC print mode: provide isolated cwd and exact owned paths, scoped Read/Edit/Write plus Glob/Grep permissions and structured output. The prior pilots did not grant shell access; preserve that default. Grant a specific bounded shell command only when necessary and authorized. Preserve the configured provider; do not choose a new paid endpoint or change authentication. Require actual edits and relevant tests run by Codex/Verifier; CC self-tests remain separate from acceptance.
- Verifier: use a fresh Codex session or independent subagent without inherited turns, its own worktree, and frozen goal/criteria. Send candidate files and source evidence after criteria freeze. Do not send the implementation conversation.
- Process capture: use argv arrays through the existing Python runtime, UTF-8 stdout/stderr files in a gitignored local evidence directory, a PID/start record written immediately after launch and an end/exit record in `finally`. Record a timeout as a timeout, retaining partial output. On Windows launch background helpers hidden. Do not restart or globally kill unrelated agent/server processes.

These are transport patterns, not proof that any browser, video tool, vendor or task works. Preserve tool errors, empty outputs and permission failures in the task report. Domain-specific evidence and permission rules belong to the appropriate domain skill/task.

For this project's authorized Chrome/BrowserSkill route, read [the browser domain runbook](../../../../docs/research/orchestration-skill-validation/AGY_BROWSER_RUNBOOK.md) and the installed `browser-skill`. Its thin transport is `tools/agy_browser_bridge.py`; runtime profile, exact URLs, policy and captures stay private under `.local`. Match the agent prompt to the permitted transport: forbidding command execution while requiring a CLI browser makes that handoff impossible. Grant only the reviewed fixed script, never all shell, Python or BrowserSkill commands. A successful ROOT transport smoke test is not AGY autonomous research. Re-probe current readiness on reuse; do not hardcode yesterday's context into the base skill.
