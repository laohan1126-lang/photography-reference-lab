## 一、 廓形 DNA (Silhouette DNA)

王昭君「长夜焕生」的整体外轮廓不是传统的“长裙古风神女”，而是融合了**深海刺胞动物门水母纲（Medusozoa）**与**现代高级定制女装（Haute Couture）**的仿生几何廓形。

```
              [扁平椭圆水母伞盖帽顶]
                    /      \
             [紧致圆润波波头 (Bob Cut)]
                    |      |
             [修长颈项 + 锁骨骨感]
                    \      /
             [X形收腰: 硬质抹胸 + 镂空腰腹]
                    /      \
            [扇贝形多层波浪外撑短裙摆]
                   /   ||   \
      [水下微拂触须飘带] || [双层透光水母燕尾拖尾]
                       ||
              [修长紧绷足背 + 极简水晶跟]
```

### 1.1 核心外轮廓特征与官方锚点对照
1. **水母钟形冠冕与悬垂面纱**：
   - 官方实证：[`OFFICIAL_006`](refs/00_OFFICIAL/OFFICIAL_006_headpiece_jellyfish_veil.webp) 与 [`OFFICIAL_012`](refs/00_OFFICIAL/OFFICIAL_012_headpiece_top_down_view.webp)。
   - 外轮廓呈现上凸下张的伞状拱形，边缘垂落细密褶皱短纱（遮额至眼部），两侧带有长触须垂落。
   - **实拍防走形要点**：必须保持伞盖横向跨度与肩宽的黄金比例（伞盖宽约为肩宽的 1.1~1.2 倍），过小会沦为普通的贝雷帽，过大会压垮人物比例。
2. **水母波波头发型 (Bob Cut)**：
   - 官方实证：[`OFFICIAL_002`](refs/00_OFFICIAL/OFFICIAL_002_character_detail.webp) 与 [`OFFICIAL_010`](refs/00_OFFICIAL/OFFICIAL_010_hair_structure_back_view.webp)。
   - 发长精确收束在下颌角与后颈交界处，后枕部呈圆润内扣球弧形，头顶向上翘起一根微卷分叉的触角呆毛。
   - **辨识度红线**：严禁将假发梳成普通仙侠直长发或散乱披肩发，波波头的克制几何圆弧是与传统古风王昭君彻底区分的视觉标记。
3. **扇贝形仿生短裙摆与燕尾长拖尾**：
   - 官方实证：[`OFFICIAL_003`](refs/00_OFFICIAL/OFFICIAL_003_model_turnaround_front.webp)、[`OFFICIAL_004`](refs/00_OFFICIAL/OFFICIAL_004_model_turnaround_back.webp)、[`OFFICIAL_007`](refs/00_OFFICIAL/OFFICIAL_007_costume_tail_structure.webp)。
   - 正面短裙由三组扇形花瓣交叠，边缘内置骨架支撑，保持向外微翘的波浪张力；后部则倾泻双层渐变透光长拖尾。
   - 高定工艺借鉴：[`COSTUME_003`](refs/01_COSTUME/COSTUME_003_iris_van_herpen_hydrozoa.webp) 与 [`COSTUME_004`](refs/01_COSTUME/COSTUME_004_iris_van_herpen_pleated_fin.webp)（Iris van Herpen 仿生水母褶皱结构）。

## 三、 色彩 DNA (Color DNA)

根据官方原画 [`OFFICIAL_001`](refs/00_OFFICIAL/OFFICIAL_001_key_visual.webp) 与特写 [`OFFICIAL_002`](refs/00_OFFICIAL/OFFICIAL_002_character_detail.webp) 的精准采样建立**三级色彩配比法**：

```
+---------------------------------------------------------------------------------+
|  深海靛蓝 / 墨黑基底 (#060C1B ~ #0E1B38) [70% 画面沉降面积]                      |
|  +---------------------------------------------------------------------------+  |
|  |  冷青生物荧光 / 冰川蓝 (#2CE8D6 ~ #6FE3FF) [20% 人物与水母中景发光]          |  |
|  |  +---------------------------------------------------------------------+  |  |
|  |  | 破晓晨曦暖金 (#FF9431) [10% 顶逆光]  +  AG战队红 (#DC2626) [1% 视觉锚点] |  |  |
|  |  +---------------------------------------------------------------------+  |  |
|  +---------------------------------------------------------------------------+  |
+---------------------------------------------------------------------------------+
```

### 3.1 色彩禁忌与防漂移法则
1. **拒绝死黑单色**：纯黑背景会剥夺深海的空间景深，背景深蓝阴影区必须保留 `#060C1B` ~ `#0E1B38` 的深靛蓝空气感。
2. **严禁全画惨蓝**：若无右上角 `#FF9431` 暖金晨光与胸前 `#DC2626` 红色核心的刺破介入，整组片子会沦为平庸沉闷的低温水底写生。
3. **肤色纯净度保护**：冷青色生物光只允许作为轮廓光与环境修饰光，面部受光区必须以高显色中性白光打底，防止模特脸部变成发青发灰的“溺水色”。

## 四、 光影 DNA (Light DNA)

本套视觉系统的灵魂在于**“冷暖对冲双轮廓”**与**“水光动态焦散”**的共存。

```
              [破晓暖金强逆光 (3200K~3800K + 蜂巢束光筒)]
                                    \
                                     \
 [深蓝背景光]                         \
      |                                \
 [背景黑丝绒]                          [人物水母伞盖 & 暖肩轮廓]
                                       /                      \
                                      /                        \
 [冷青轮廓灯棒 (Cyan LED Bar)] ----> [人物左侧冷边缘]     [正面微弱柔光 (高显色中性白)]
                                                               |
                                            [地面反光板: 消除帽檐深重下眼眶黑影]
                                                               |
                                       [正面/侧向焦散投射灯 (Water Caustics)]
```

### 4.1 光学组件三要素
1. **焦散水波纹 (Caustics Projection)**：
   - 现场实测参考：[`LIGHTING_001`](refs/04_LIGHTING/LIGHTING_001_water_ripple_projection.webp) 与 [`LIGHTING_002`](refs/04_LIGHTING/LIGHTING_002_dual_color_rim_lighting.webp)。
   - 水波纹灯不仅投射在背景上，更应以低角度掠过模特锁骨、脸颊与水母帽檐，确立身处万米深海的沉浸介质感。
2. **冷暖双色温切边 (Dual-Color Temperature Separation)**：
   - 一侧由青天色（Cyan）勾勒身体边缘与假发，另一侧（尤其是破晓来临的右上方）由暖金强光切割。两道截然相反色温的光线交汇于模特头顶水母薄纱，形成光芒撕裂深渊的视觉张力。
3. **实拍道具内自发光 (Practical Motivation Light)**：
   - 手持发光晶球（[`POSE_002`](refs/03_POSE/POSE_002_hands_cupping_bioluminescence.webp)）与竖琴内部自发光。真实光源打在模特手掌、下巴与鼻尖，产生自然的次表面红血色漫射，这是任何 CG 后期画光都无法比拟的物理真实感。

## 五、 动势 DNA (Motion DNA)

深海环境下的重力与地面截然不同，王昭君的体态动势必须遵循**“水的浮力流体动力学”**。

```
[水母舒张 (Expansion)] <===================> [水母收缩 (Contraction)]
         |                                             |
   手臂如触须舒展                                躯体向内核微蜷
   裙摆长纱向四周散开                            双腿交叉抱膝或微弓
   发丝轻扬失重                                  沉入深渊蓄力沉眠
   (对应 Shot 01, Shot 08, Shot 09)             (对应 Shot 03, Shot 07)
```

### 5.1 关键动作物理规范
- **指尖轻灵感**：手指十指严禁死板紧绷或拳头紧握，必须呈现水母触手般的柔缓屈伸（参考 [`POSE_002`](refs/03_POSE/POSE_002_hands_cupping_bioluminescence.webp)）。
- **足尖延伸感**：水下失重状态下，脚掌自然呈芭蕾足尖绷直（En Pointe）下压态，拉长小腿到脚背的纵向线条（参考 [`OFFICIAL_013`](refs/00_OFFICIAL/OFFICIAL_013_shoes_and_anklet_detail.webp)）。
- **纱幔与发丝的动态捕捉**：利用慢速快门同步闪光（[`STYLE_003`](refs/02_STYLE/STYLE_003_underwater_dress_flow.webp)）或微风机，抓取织物飘带在空中滞空的瞬间。
