# 王昭君·长夜焕生 漫展现场姿态动作链系统 (POSE_CHAINS)

> **版本**：V2.1 Expo Field Edition  
> **使用场景**：大型漫展现场快速 COS 摄影（人流密集、拍摄时间极短、单摄影师无助理）  
> **核心机制**：从同一个基础机位/站位出发，仅通过**极小幅度的肢体微调（Micro-adjustments）**，在 1~2 分钟内连续产出 4~6 张完全不同构图与情绪的高完成度成片。  
> **口令原则**：摄影师口令（`director_script`）全部为普通人一听就懂的通俗中文，杜绝舞蹈演员专属术语。

## CHAIN 01: 【清冷神性站姿链】(Cool Ethereal Standing)

- **核心目标**：刚就位、Coser 尚未完全进入状态时的热身连拍。无道具、纯靠体态微调出片。
- **模特基础站位**：面向摄影师方向，但身体右侧微转 30°，重心落在后脚（右脚），前脚（左脚）脚尖自然虚点地面。
- **摄影师机位**：模特正前方偏左 15°，平视略低 10cm（胸口高度），保持 2.5 米距离。
- **推荐镜头**：Sony 50mm f/1.8（光圈开至 f/2.0~f/2.5，虚化漫展杂乱背景）。
- **漫展可执行等级**：`A`（无需道具，45秒搞定）。

```
[P1: 正面微侧审视] ---> [P2: 视线微扬远眺] ---> [P3: 单手轻触头纱] ---> [P4: 垂眸凝息沉思] ---> [P5: 侧身正面交汇]
 (身体30°, 看镜头)      (身不动, 眼神看上方)   (抬右手捏纱角)        (低头看掌心)          (右肩微后收, 眼神回打)
```

### 连续动作与摄影师口令：

#### P1: 正面微侧审视 (Half Body / 3/4)
- **动作变化**：身体朝向右侧 30°，右肩微后收，头部朝向摄影师，眼神平视镜头。
- **摄影师口令**：“身体往你右边稍微侧一点，不要正正对着我。右肩膀放松稍微往后撤一点，脸转回来找镜头。好，眼神稍微清冷一点，下巴别抬太高，看这里，啪（快门）。”
- **微调要点**：避免正面拍成大头照；双肩形成高低落差。
- **常见失误**：肩膀僵硬耸起，眼神发狠。

#### P2: 视线微扬远眺 (Bust / Half Body)
- **动作变化**：身体完全不动，头部向原方向保持，视线从镜头平滑移到摄影师头顶上方约 30cm 处。
- **摄影师口令**：“身体别动！脸保持住，视线从镜头慢慢移到我头顶上面，像在看深海远处有光透进来，嘴唇微微放松微张一点，好，非常漂亮，啪（快门）。”
- **微调要点**：眼白不要露太多，只抬视线不仰脖子。

#### P3: 单手轻触头纱 (Half Body)
- **动作变化**：右手轻柔抬起，大拇指与食指捏住右耳侧水母帽檐的透光薄纱，手腕下沉放松，左手自然垂于大腿侧。
- **摄影师口令**：“右手慢慢抬起来，两根手指轻轻捏住帽子边上的纱，别抓一把，就捏个角！手腕放松别悬空用力，手肘贴着身体。好，眼神重新回来看镜头，啪（快门）。”
- **微调要点**：手指切忌紧绷抓握，呈兰花指自然放松态。

#### P4: 垂眸凝息沉思 (Closeup / Bust)
- **动作变化**：头部顺势向右下方微垂 15°，视线落在左手虚握的手心方向。
- **摄影师口令**：“保持刚才捏纱的动作，头轻轻往左下低一点点，看着你的左手手心，像在看着水母沉睡一样，表情放空一点……好，别动，啪（快门）。”
- **微调要点**：下巴内收拉长后颈，避免低头挤出双下巴。

#### P5: 侧身正面交汇 (Full Body / 3/4)
- **动作变化**：松开捏纱的手，身体再往右侧转一点，下巴微扬，眼神锐利回眸看镜头。
- **摄影师口令**：“手放下来，身体再侧过去一点，下巴轻轻抬一下，猛地转回头看我！眼神带一点威严，好，停住，啪（快门）。”

## CHAIN 02: 【小马扎端坐与抚裳链】(Stool Seated & Skirt Flourish)

- **核心目标**：拍摄 15 分钟后 Coser 容易腿酸，此时拿出折叠小马扎，不仅能让 Coser 休息，还能拍出极具高级感的深海静谧坐姿。
- **模特基础站位**：侧身坐于小马扎前 1/3 边缘（不可整个人陷进去），靠近镜头的腿向前伸直绷紧足尖，另一条腿自然收在凳下。
- **摄影师机位**：前侧 45°，微俯或平视，距离 2 米。
- **推荐镜头**：Sony 50mm f/1.8 或 24-240mm @ 50–70mm。
- **漫展可执行等级**：`B`（需自备折叠小马扎，90秒搞定）。

```
[P1: 侧坐抚膝定势] ---> [P2: 探身轻抚裙角] ---> [P3: 单手虚托下颌] ---> [P4: 仰身展臂微光] ---> [P5: 抱膝敛神沉眠]
 (前腿伸直, 背立直)    (上身前倾, 展开短裙)   (手指轻靠下巴)        (上身后仰, 单臂舒展)   (双手抱单膝, 闭眼)
```

### 连续动作与摄影师口令：

#### P1: 侧坐抚膝定势 (Full Body / 3/4)
- **摄影师口令**：“咱们坐马扎前边一点，别坐满了。右腿往我这边大大方方伸出来，脚尖下压绷直！双手叠放在左大腿上。腰挺起来，肚子收一收。看我镜头，下巴收一点，好，啪。”
- **微调要点**：前腿绷直脚尖是拉长腿部线条的核心诀窍。
- **常见失误**：后背驼背，小腹衣服堆褶。

#### P2: 探身轻抚裙角 (3/4 / Half Body)
- **摄影师口令**：“身体稍微往前探一点点，右手顺着大腿滑下去，轻轻提一下水母裙摆的花边。眼神看你的右手裙角，别看我。好的，保持这个好奇的眼神，啪。”
- **微调要点**：上身保持脊柱挺直前倾，不可弯腰拱背。

#### P3: 单手虚托下颌 (Half Body / Bust)（对应参考 [`POSE_002`](../refs/03_POSE/02_STOOL_SEATED/POSE_002_seated_chin_gesture.webp)）
- **摄影师口令**：“身体坐直回来，右手抬起来，食指和中指轻轻贴在下巴边上，千万别真用力托脸！脸稍微朝你的左边转 15 度，眼神看我镜头右边。表情温柔一点，啪。”
- **微调要点**：手指虚贴，避免面部肉被挤压变形。

#### P4: 仰身展臂微光 (Full Body / 3/4)
- **摄影师口令**：“上身慢慢往后仰一点，左手臂向后撑在小马扎边缘，右手向前上方缓缓伸出去，像在水里抓气泡。眼睛跟着手走，看头顶！脚尖继续绷紧，啪。”
- **微调要点**：胸腔打开，展现优美颈肩线条。

#### P5: 抱膝敛神沉眠 (Full Body)
- **摄影师口令**：“双腿收回来一点，双手抱住右膝盖，头轻轻搭在膝盖上，眼睛闭上，深呼吸，像在深海里睡着了……保持住，啪。”
- **微调要点**：面部放松，睫毛不要因用力紧闭而颤抖。

## CHAIN 03: 【回眸与侧颜轮廓链】(Turning & Profile Rim)

- **核心目标**：王昭君大露背与水母拖尾、波波头后颈是官方重要设计点（[`OFFICIAL_004`](../refs/00_OFFICIAL/OFFICIAL_004_model_turnaround_back.webp)）。本链专门收割背部与回眸神图。
- **模特基础站位**：背对摄影师，向右转 15°，右脚在前，左脚在后。
- **推荐镜头**：Sony 50mm f/1.8（大光圈虚化身后漫展路人）。
- **漫展可执行等级**：`A`（40秒搞定）。

```
[P1: 纯背影拖尾挺立] ---> [P2: 侧颜90°剪影] ---> [P3: 120°经典回眸找镜头] ---> [P4: 回眸提纱掩面]
 (展示露背与燕尾)       (下巴微扬, 鼻尖剪影)   (身体背向, 眼神锁镜头)     (右手搭肩轻扯头纱)
```

### 连续动作与摄影师口令：

#### P1: 纯背影拖尾挺立 (Full Body / 3/4)
- **摄影师口令**：“完全背对着我站好，挺胸沉肩，双手在身前自然垂下。把水母拖尾理顺。不用回头，就保持安静站立的背影，好，啪。”
- **微调要点**：展现背部脊柱沟与水母拖尾的双层层次。

#### P2: 侧颜90°剪影 (Bust / Half Body)
- **摄影师口令**：“身子保持背对，头慢慢往你的右边转 90 度，完全露出侧脸！下巴轻轻扬起来一点，嘴唇微张。眼神看正前方虚空，把你的下颌线亮出来，漂亮，啪。”
- **微调要点**：下巴抬起 15°，让侧脸轮廓和睫毛形成清晰剪影。

#### P3: 120°经典回眸 (Half Body / Bust)
- **摄影师口令**：“身体别动！肩膀千万不要跟着转过来！仅把头再转多一点，眼神回来死死锁住我的镜头！下巴稍微往下压一点点，眼神带一点冷冽与审视，看我！啪！”
- **微调要点**：肩膀不动，仅头部旋转，身体扭转产生极具张力的线条。
- **常见失误**：整个人转过来变成侧面照；转头幅度过大露出过多眼白。

#### P4: 回眸提纱掩面 (Bust / Closeup)
- **摄影师口令**：“保持回眸！右手抬起来搭在右肩上，指尖顺便勾住垂下来的薄纱，稍微遮住一点下半张脸，露出眼睛。眼睛看我，睫毛扬起来，绝美，啪！”

## CHAIN 06: 【小幅度转身与裙摆动态链】(Subtle Turn & Flowing Hem)

- **核心目标**：漫展空间有限，无法进行大幅奔跑，本链专为“原地旋转半圈（180°）”设计，抓取裙摆和头纱飘扬瞬间。
- **相机设置建议**：Sony A7M4 调至连续快门（Hi+），快门速度不低于 1/250s（保证凝固清晰面部）。
- **推荐镜头**：Sony 24-240mm @ 35–50mm。
- **漫展可执行等级**：`A`（45秒搞定）。

### 连续动作与摄影师口令：
- **P1 准备**：“先背对我站好，重心放在左脚。”
- **P2 口令与动作**：“听我口令：一、二、转！顺时针向右转回头，脚下原地拧半圈，裙子甩起来的时候，脸迅速找到我的镜头！”
- **P3 抓拍**：摄影师按住连拍，连续捕获：
  1. 转身中途长纱腾空；
  2. 身体定住但裙角仍在惯性翻飞；
  3. 定格后的回眸冷傲微笑。

- **推荐镜头**：Sony 24-240mm @ 28–35mm。
